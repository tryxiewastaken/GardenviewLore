# Archivos del Laboratorio

Sitio estático (HTML + CSS + JS) con la fuente Fredoka One de Google Fonts.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (público).
2. Sube TODOS los archivos de este ZIP a la raíz del repo (Add file → Upload files).
3. Ve a Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`. Guarda.
4. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Editar contenido
Todos los textos están en `data.js`. Cada escrito usa `N(id, tipo, título, fecha, escritor, [fragmentos], {to, stain})`.
